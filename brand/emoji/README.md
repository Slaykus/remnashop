# Премиум-эмодзи Rain VPN

Пак из 34 иконок под бренд Rain VPN и обвязка, которая подставляет их id
в переводы бота.

Иконки — векторные (`icons.mjs`), растр собирается из них. Править нужно
исходник, а не PNG: перерисовка всего пака занимает секунду.

## Что где

| Путь | Что это |
|---|---|
| `icons.mjs` | Исходники: палитра, SVG-тела иконок, запасные эмодзи, привязка к ключам |
| `build.mjs` | Рендер в PNG 100×100 + контактный лист + `MAPPING.md` |
| `apply-ids.mjs` | Подстановка id премиум-эмодзи в `assets/translations/*/custom.ftl` |
| `png/` | Готовые файлы для загрузки в @Stickers |
| `svg/` | Те же иконки в векторе |
| `contact-sheet.png` | Весь пак одним листом — крупно и в размере кнопки |
| `MAPPING.md` | Таблица «файл → ключ перевода» (генерируется, руками не править) |

## Пересборка

```bash
cd brand/emoji && npm install && node build.mjs
```

## Как завести пак в бота

**1. Создать набор.** Отправьте `/newemojipack` боту
[@Stickers](https://t.me/Stickers) и загрузите файлы из `png/` **в том же
порядке, в каком они идут в `MAPPING.md`** — дальше это сэкономит время при
заполнении id. Формат уже соответствует требованиям Telegram: PNG 100×100 с
прозрачным фоном.

**2. Собрать id.** Перешлите каждый эмодзи из готового набора боту
[@getidsbot](https://t.me/getidsbot) — он вернёт поле `custom_emoji_id`.

**3. Заполнить `ids.json`.** Скопируйте шаблон и подставьте номера:

```bash
cp ids.example.json ids.json
```

Заполнять можно частями — иконки с пустым id просто пропускаются, и их ключи
остаются на обычных Unicode-эмодзи.

**4. Подставить в переводы.**

```bash
node apply-ids.mjs --check
```

Прогон с `--check` только показывает, что изменится. Без флага скрипт правит
`custom.ftl` обеих локалей. Запускать можно сколько угодно раз: он заменяет
ранее вставленные теги, а не наслаивает их.

**5. Перезапустить бота**, чтобы перечитать переводы:

```bash
docker compose down && docker compose up -d
```

## Как это работает

В `custom.ftl` эмодзи записывается тегом вокруг обычного:

```ftl
.connect = <e id="5447410659077661506">⚡</e> Подключиться
```

Виджеты `Emoji*` из `src/telegram/widgets/tg_emoji.py` вырезают тег из текста
кнопки и кладут номер в поле `icon_custom_emoji_id` — у кнопки Telegram это
отдельное поле, а не часть подписи. Обычный эмодзи внутри тега остаётся
запасным вариантом: его увидят клиенты без поддержки кастом-эмодзи.

Право отправлять кастом-эмодзи бот получает от Telegram Premium владельца
(Bot API 9.4) либо от платного юзернейма с Fragment. Без этого API вернёт
ошибку на любое сообщение с тегом.

## Границы правки

`apply-ids.mjs` трогает только участок между маркерами:

```ftl
# >>> rain-emoji
...
# <<< rain-emoji
```

Маркеры удалять нельзя — без них скрипт пропустит файл. Всё, что вне
маркеров (админ-панель, названия планов, тексты сообщений), остаётся нетронутым;
такие ключи при необходимости правятся вручную.

Шесть иконок (`warning`, `profile`, `shield`, `traffic`, `clock`, `logo`) не
привязаны к кнопкам — они для шапок и блоков в тексте сообщений, куда тег
вставляется руками.

## Палитра

| Токен | Цвет | Роль |
|---|---|---|
| `blue` | `#4C9AE8` | основной акцент бренда |
| `cyan` | `#6FD3F0` | дождь, вторичный акцент |
| `cloud` | `#EEF4FB` | облако, светлые плоскости |
| `navy` | `#16283F` | контуры и тени |
| `slate` | `#41618C` | нейтральные плашки |
| `gold` | `#F5C451` | молния, промокоды, подарки |
| `green` | `#4FD18B` | подтверждение |
| `red` | `#F2685E` | удаление |
| `violet` | `#A78BFA` | баллы |

Иконки рисуются крупными заливками без тонких обводок: в кнопке глиф
рендерится примерно в 20 пикселей, и линии тоньше 6 единиц там пропадают.
