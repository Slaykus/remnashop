# Премиум-эмодзи Rain VPN

Пак из 34 анимированных иконок под бренд Rain VPN и обвязка, которая
подставляет их id в переводы бота.

Иконки собираются кодом: SVG-кадры рисуются функцией фазы, растеризуются и
кодируются в WEBM. Править нужно исходники, а не готовые файлы — пересборка
всего пака занимает пару минут.

## Идея пака

Весь набор собран из одного словаря брендовых примитивов, а не из
заимствованных символов:

| Примитив | Значение |
|---|---|
| **Капля** | атом системы: единица, устройство, день, порция трафика |
| **Облако** | сам сервис Rain VPN |
| **Дуга / купол** | защита; рифмуется с дугами логотипа |
| **Разряд** | скорость, момент соединения |
| **Кольцо** | цикл, срок, продление |
| **Струя** | поток трафика |

Пак делится на два слоя. **Ядро** (14 иконок) несёт смысл сервиса — там
работает полный словарь: подписка это капля со счётчиком срока, продление —
круговорот воды, приглашение — капля, делящаяся надвое. **Утилита**
(20 иконок) — «назад», «отмена», «QR» и прочее, где узнаваемость важнее
метафоры: силуэты привычные, брендовыми их делают палитра, градиентная
пластика, свечение и капля-акцент.

Полный перечень с описанием каждой иконки — в [MAPPING.md](MAPPING.md).

## Что где

| Путь | Что это |
|---|---|
| `style.mjs` | палитра, градиенты, тени, блики, функции анимации |
| `primitives.mjs` | геометрия брендовых примитивов — общая для обоих слоёв |
| `icons-core.mjs` | 14 иконок брендового ядра |
| `icons-util.mjs` | 20 иконок утилитарного слоя |
| `wiring.mjs` | привязка иконок к ключам переводов и запасным эмодзи |
| `pack.mjs` | сборка: отрисовка + проводка, проверка их согласованности |
| `build.mjs` | рендер в WEBM, превью, генерация `MAPPING.md` |
| `apply-ids.mjs` | подстановка id в `assets/translations/*/custom.ftl` |
| `webm/` | готовые файлы для загрузки в @Stickers |
| `preview-grid.png` | весь пак одним кадром |
| `preview-motion.gif` | весь пак в движении |
| `preview-phases.png` | фазы петли построчно — для отладки анимации |

Проводка вынесена в отдельный файл намеренно: арт и привязка к ключам
меняются в разном темпе, а когда они лежали вместе, запасные эмодзи
разъехались с `custom.ftl`. `pack.mjs` падает, если иконке не задана
проводка или проводка указывает на несуществующую иконку.

## Пересборка

Нужны Node и ffmpeg с `libvpx-vp9`.

```bash
cd brand/emoji && npm install && node build.mjs
```

Сборка проверяет вес каждого файла и завершается с ошибкой, если что-то
переросло лимит Telegram в 256 КБ. Флаг `--preview` собирает только превью,
без кодирования.

## Как завести пак в бота

**1. Создать набор.** Отправьте `/newemojipack` боту
[@Stickers](https://t.me/Stickers), выберите видео-формат и загрузите файлы
из `webm/` **в порядке строк [MAPPING.md](MAPPING.md)** — так проще заполнять
`ids.json`. Формат уже соответствует требованиям: VP9, ровно 100×100,
1.5 с при 30 FPS, с альфа-каналом, без звука.

**2. Собрать id.** Перешлите каждый эмодзи из готового набора боту
[@getidsbot](https://t.me/getidsbot) — он вернёт поле `custom_emoji_id`.

**3. Заполнить `ids.json`.**

```bash
cp ids.example.json ids.json
```

Заполнять можно частями: иконки с пустым id пропускаются, и их ключи
остаются на обычных Unicode-эмодзи.

**4. Подставить в переводы.**

```bash
node apply-ids.mjs --check
```

С `--check` скрипт только показывает, что изменится. Без флага правит
`custom.ftl` обеих локалей. Запускать можно многократно: он заменяет ранее
вставленные теги, а не наслаивает их, и сохраняет переводы строк файла.

**5. Разложить на сервере.** `custom.ftl` лежит в volume бота и при
обновлении образа **не перезаписывается** — энтрипоинт копирует шаблон
только если файла нет. Обновлённый файл нужно положить на сервер вручную,
затем перезапустить бота:

```bash
docker compose down && docker compose up -d
```

## Как это работает

В `custom.ftl` эмодзи записывается тегом вокруг обычного:

```ftl
.connect = <e id="5447410659077661506">⚡</e> Подключиться
```

Виджеты `Emoji*` из `src/telegram/widgets/tg_emoji.py` вырезают тег из текста
кнопки и кладут номер в поле `icon_custom_emoji_id` — у кнопки Telegram это
отдельное поле, а не часть подписи. Обычный эмодзи внутри тега остаётся
запасным: его увидят клиенты без поддержки кастом-эмодзи.

Право отправлять кастом-эмодзи бот получает от Telegram Premium владельца
либо от платного юзернейма с Fragment (Bot API 9.4).

## Границы правки

`apply-ids.mjs` трогает только участок между маркерами:

```ftl
# >>> rain-emoji
...
# <<< rain-emoji
```

Маркеры удалять нельзя — без них скрипт пропустит файл. Всё, что вне
маркеров (админ-панель, названия планов, тексты сообщений), остаётся
нетронутым и правится вручную.

Шесть иконок (`traffic`, `shield`, `logo`, `clock`, `profile`, `warning`) не
привязаны к кнопкам — они для шапок и блоков в тексте сообщений.

## Палитра

| Токен | Основной цвет | Роль |
|---|---|---|
| `blue` | `#3B82E8` | основной акцент бренда |
| `cyan` | `#5FD3F5` | дождь, вторичный акцент |
| `cloud` | `#E6EFFA` | облако, светлые плоскости |
| `slate` | `#41618C` | нейтральные плашки |
| `gold` | `#F7BA45` | разряд, промокоды, предупреждения |
| `green` | `#3FD48A` | подтверждение |
| `red` | `#F2685E` | удаление и отмена |

Каждый цвет задан рампой из трёх стопов: светлый верх, насыщенная середина,
тёмный низ. Именно рампа плюс размытая подложка и верхний блик дают объём.

Иконки рисуются крупными заливками без тонких обводок: в кнопке глиф
рендерится примерно в 20 пикселей, и линии тоньше шести единиц там пропадают.

Одна тонкость SVG: градиент в системе `objectBoundingBox` не работает на
строго горизонтальной или вертикальной линии — у неё нулевая высота рамки,
и обводка не отрисуется. Для таких штрихов берите сплошной цвет.
